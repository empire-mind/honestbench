# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

We support the latest release of this project. Please keep your copy up to date.

## Reporting a Vulnerability

Please report security vulnerabilities **privately** using GitHub's private
vulnerability reporting: the **Security** tab → **Report a vulnerability**
on this repository. Do **not** open a public issue for a suspected vulnerability.

Please include:
- a description of the vulnerability and its potential impact,
- steps to reproduce,
- any relevant logs, screenshots, or a non-destructive proof-of-concept.

We aim to acknowledge reports promptly and will keep you informed as we investigate.
